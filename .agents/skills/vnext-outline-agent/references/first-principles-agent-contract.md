# VNext 叙事工程第一性原理执行契约 (First-Principles Narrative Agent Contract)

> **本契约直接作为 Agent 行为的最高硬约束，彻底根除“一句话大纲骗局”与“摘要注水”问题。**

---

## 一、 核心红线与禁令 (Strict Negative Invariants)

1. **严禁“一句话结果摘要”冒充章节大纲**：
   - 任何章节大纲如果只有“谁打了谁 / 主角获胜 / 众人震惊”等结果句，一律判定为 `DRAMATIC_PAYLOAD_CAPACITY_SHORTFALL`（剧情承载量不足），禁止进入交付状态。
2. **严禁虚构占位符（Zero Anonymous Placeholders）**：
   - 严禁出现“路人甲、路人乙、侍卫A、长老一、黑衣人、神秘人、恶奴”等无名无姓工具人；
   - 任何承担台词、阻力、行动或见证功能的个体，必须拥有**真实姓名、具体职位、自私动机与有限认知视界**。
3. **严禁天降与机械降神（Zero Deus Ex Machina）**：
   - 所有关键道具、神兵、解药、暗线、援军，必须在至少前 3—5 章甚至前 1 卷拥有可追溯的埋设记录（Provenance）。
4. **严禁为了反转而强行降智（Zero Idiocy Inversion）**：
   - 反派的每一次反制必须基于其自身阶级利益与现有情报的最优解；主角的破局必须依靠更高维度的底牌或严密信息差计算，严禁反派突然发疯或送人头。

---

## 二、 4000—6000 字正文单章承载硬标准 (DPC Protocol)

每一章的详细施工图必须在结构上提供以下物理量：

```text
单章 4000—6000 字高密度正文
├── 3 个物理场景转换 (Scene 1 -> Scene 2 -> Scene 3，镜头与时空转移)
├── 3 个局部冲突集群 (Payload Clusters，多方利益拉扯)
└── 6 个原子级可演节拍 (Stageable Core Beats)
    ├── B1 [ACTION]: 主角/施动者基于明确目标的初次动作
    ├── B2 [COUNTERMOVE]: 对手依据自身利益的强力反制与出牌
    ├── B3 [REPLAN]: 局势受阻后的战术微调与压强升级
    ├── B4 [REVELATION]: 关键信息差破裂 / 底牌真相大揭示
    ├── B5 [COST]: 破局伴随的不可逆物理/社会/心理代价
    └── B6 [HOOK]: 撕开更高维度危机的引信，抛出章末绝对追读力
```

---

## 三、 300 章级长篇架构推进黄金模型 (Volume Horizon)

长篇网文不靠注水，靠**地图版图、权力半径、敌人层级与世界真相的梯级跃迁**：

- **第 1 卷（地方郡城/初入江湖）**：打破地方垄断，建立初始身份与武力威慑，拿到灭门第一层罪证；
- **第 2 卷（经济中枢/商战暗夜）**：摧毁敌对财阀资金链，整合天下情报与刺客网络，截获高层通敌密信；
- **第 3 卷（边防前线/军权战神）**：执掌帝国最强铁骑，阵前斩将封狼居胥，以军威威慑朝堂奸党；
- **第 4 卷（国都九门/深宫权谋）**：天机破阵，朱雀门斩杀主谋国舅，百官臣服，揭开皇权核心丑闻；
- **第 5 卷（皇朝绝巅/仙门决战）**：斩灭魔化伪帝，手撕仙门太上长老，彻底踏平吃人道统；
- **第 6 卷（万界重铸/逍遥人间）**：扶持明君践祚，重定天下法度，破除上界禁制，红尘归隐圆满大结局。
